# silica-setup

L'assistente al primo avvio di [Silica](https://github.com/silica-linux/silica-desktop): lingua,
tastiera, rete, account, aspetto e privacy, la prima volta che il sistema parte. È un'app
Flutter come Mustache: dipende da `silica_ui` e si costruisce con
`cargo xtask bundle <percorso>` di silica-desktop.

I comportamenti si misurano su macOS 27 in silica-reference; testi e grafica sono nostri.
